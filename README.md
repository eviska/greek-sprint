# Особистий інтерактивний зошит з грецької

Це персональний навчальний простір Тетяни: її нотатки з уроків, слова, тексти, граматика й інтерактивні вправи з грецької. Це не готовий продукт для інших користувачів і не публічний навчальний курс.

AI-агент працює з матеріалами, коли ця тека відкрита як робоча тека в Codex: допомагає опрацьовувати нові уроки й PDF, доповнює дані та сторінки відповідно до `CONTENT_GUIDE.md` і за потреби змінює сам тренажер. Вебсторінка — локальний інтерактивний інтерфейс до цих нотаток. Git і приватний GitHub-репозиторій зберігають історію змін та резервну копію; сайт працює на цьому комп’ютері й сам по собі не публікується в інтернет.

## Запуск

1. Відкрий Terminal і перейди до теки проєкту:

   ```sh
   cd /шлях/до/теки/greek-sprint
   ```

   На macOS можна набрати `cd `, перетягнути теку проєкту у вікно Terminal і натиснути Enter.

2. Запусти локальний сервер:

   ```sh
   python3 server.py
   ```

3. Відкрий <http://127.0.0.1:8000> у браузері. На Windows, якщо команда `python3` недоступна, спробуй `py server.py` або `python server.py`. Щоб зупинити сервер, повернись у Terminal і натисни `Ctrl+C`.

Не відкривай `index.html` подвійним кліком: сторінка має завантажити локальні JSON-файли через сервер, а сервер записує результати у файл прогресу.

## Файли даних

- `data/cards.json` — колода. На кожну картку потрібні незмінний UUIDv4 `id`, грецький текст `greek`, переклад `ukrainian`, тип `type` (`phrase`, `word` або `question`) і джерело `source`.
- `data/stories/` — окремі JSON-файли з повними історіями для розділу читання; `index.json` перелічує доступні історії. Тексти збережені з відновленими пробілами й пунктуацією.
- `data/lessons/` — окремі JSON-уроки та їхні PDF-джерела; `index.json` перелічує уроки. Кожен урок відкривається як власна довга сторінка за адресою `/lessons/<id>`; прогрес уроків зберігається в `data/progress.json`.
- `data/grammar/` — окремі модулі граматичних тем і їхній індекс; сторінка `grammar.html` показує бібліотеку, а спільний шаблон `grammar-topic.html` відкриває пояснення, приклади й інтерактивну практику за ID теми.
- `data/progress.json` — локальна база прогресу: відповіді, правильні/неправильні спроби, серія правильних відповідей, інтервал і час наступного повторення. Сервер створить файл, якщо його видалити.
- `data/retired-cards.json` — архів карток, які скрипт прибрав з активного тренування після п’яти правильних відповідей. Прогрес таких карток зберігається, їх можна повернути з тим самим ID.
- `prune_cards.py` — перевіряє прогрес і переносить знайомі картки з `data/cards.json` до архіву. Запуск: `python3 prune_cards.py`; попередній перегляд без змін: `python3 prune_cards.py --dry-run`.
- `CONTENT_GUIDE.md` — правила, за якими нові тексти з чату перетворюються на короткі фрази, слова, граматичні форми й запитання для колоди.
- `server.py` — локальний HTTP-сервер та API, яке читає колоду і змінює прогрес.
- `app.js` — гра, планувальник карток, звуки, підсумок раунду та вправи конструктора слів.
- `styles.css` — оформлення; `index.html` — структура сторінки.

Приклад картки:

```json
{
  "id": "e87632f8-1e2f-4a48-9275-ca3e2f281341",
  "greek": "με το αυτοκίνητό του",
  "ukrainian": "своїм автомобілем",
  "type": "phrase",
  "source": "michalis"
}
```

Коли додаєш матеріал з нового тексту, збережи нормалізовану повну історію окремим файлом у `data/stories/`, додай назву файлу до `data/stories/index.json`, а картки додай до масиву в `data/cards.json`. Створи кожному запису UUIDv4, наприклад командою `python3 -c 'import uuid; print(uuid.uuid4())'`. Зберігай виданий ID для цієї картки: не генеруй його повторно після зміни перекладу чи сортування. Для карток одного тексту використовуй спільне значення `source`. Гра сама утворює хибний переклад із іншої картки того самого типу, тож окремо позначати «правда/неправда» в колоді не треба. Перезавантаж сторінку після редагування колоди.

### Уроки

Кожен інтерактивний урок має окремий JSON у `data/lessons/` і запис у `data/lessons/index.json`. Вибір уроку відкриває окрему довгу сторінку з лексикою, граматичними примітками, читанням і всіма вправами одночасно. Відповіді перевіряються в кожній вправі, а словникові підказки розміщені поруч із завданнями. Письмову відповідь користувач оцінює самостійно; чернетка зберігається локально. Картки уроку додаються до `data/cards.json` зі спільним `source`, як у файлі уроку, і доступні у словнику з фільтром за навчальним матеріалом.

Після оновлення `server.py` зупини запущений сервер клавішами `Ctrl+C`, потім запусти його знову командою `python3 server.py`. Перевір роботу на <http://127.0.0.1:8000>: відкрий «Уроки», перевір відповіді, перезавантаж сторінку й переконайся, що прогрес та письмова чернетка збереглися. У словнику вибери матеріал нового уроку, щоб переглянути його лексику.

## Як працюють повторення

- Нові картки мають найвищу вагу вибору; картки, для яких настав час повторення, теж з’являються часто.
- Після правильної відповіді наступний інтервал росте: 1, 3, 7, 14, потім 30 днів.
- Після помилки картка повертається до короткого інтервалу приблизно в шість годин.
- Вже засвоєні картки мають малу, але ненульову ймовірність появи, щоб час від часу освіжати пам’ять.
- У межах раунду гра не повторює щойно показані картки, якщо є інші доступні.

## Погоджений напрямок розділу граматики

- `grammar.html` — бібліотека тем; кожна картка відкриває спільний шаблон `grammar-topic.html` за ID окремого JSON-модуля.
- Додавати тему тоді, коли вона з’являється в опрацьованих уроках. Повторювані правила об’єднувати; рідкісні слова й сталі фрази залишати в матеріалах, якщо окрема граматична тема не допоможе їх засвоїти.
- Пояснювати простою українською, по одному правилу за раз. Вибирати короткі, знайомі приклади й зазначати джерело матеріалу.
- Для кожної теми генерувати інтерактивну практику. За потреби в одній темі можуть бути кілька різних вправ; формат і кількість підбирати під правило, а не робити всюди один і той самий тип.
- Вправи для граматики можна створювати окремо за мотивами уроків; не потрібно дублювати вправи з PDF. Додавати нові теми й типи практики невеликими модулями після досвіду користувачки.

## Погоджений напрямок тренування письма

Поточний формат конструктора слів подобається користувачці й зафіксований як робочий напрямок для наступних вправ письма:

- Тренування використовує спільну активну колоду `data/cards.json`; окремих списків слів для письма не створювати.
- На старті показати слово грецькою, переклад і матеріал-джерело. Після натискання «Скласти слово» сховати грецький зразок.
- Складати слово з перемішаних плиток усіх його літер. Дозволити перетягування, натискання й введення з грецької клавіатури. Не додавати сторонніх літер у початковий рівень.
- Давати короткі випадкові добірки по п’ять активних карток типу `word`; джерело можна вибрати зі списку читабельних назв.
- Цей режим призначений для першого знайомства з написанням, коли вільне пригадування ще зарано. Нові рівні складності, збереження окремого прогресу письма чи інші зміни додавати лише після подальшого досвіду користувачки.

Особистий прогрес зберігається локально у `data/progress.json` і виключений із Git через `.gitignore`, тож він не надсилається до GitHub. Самі навчальні матеріали й код версіонуються в репозиторії. Для резервної копії прогресу можна окремо скопіювати `data/progress.json`; щоб почати статистику спочатку, зупини сервер і видали цей файл — наступний запуск створить порожній.
